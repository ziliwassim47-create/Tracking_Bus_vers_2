## 🔍 Troubleshooting

### If you still get "Network request failed":
1. **Verify backend is running on port 4321:**
   ```bash
   # On VPS:
   pm2 logs bus-tracker-backend | grep "Serveur en écoute"
   # Should show: http://0.0.0.0:4321
   ```

2. **Check firewall on VPS:**
   ```bash
   # Ensure port 4321 is open
   sudo ufw status
   # Or check with:
   curl http://51.91.249.6:4321/api/test
   ```

3. **Verify device can reach the server:**
   - Try opening `http://51.91.249.6:4321/api/test` in device browser
   - Should return: `{"success":true,"message":"Backend is reachable",...}`

### If backend logs show no requests:
- The issue is network/firewall related
- Check VPS firewall rules
- Verify the IP `51.91.249.6` is correct and accessible
